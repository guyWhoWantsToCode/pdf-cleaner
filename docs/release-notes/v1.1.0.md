# PDF Cleaner 1.1.0

PDF Cleaner is now a **standalone Windows app**. Download `PDFCleaner.exe`, double-click it, and you're done: no Python, no installer. This release also adds a **duplicate finder** and a **Show in folder** button.

## What's new

### Standalone app: `PDFCleaner.exe`

- One file, about 10 MB, for 64-bit Windows 10 and 11.
- Works exactly like before: a black window opens and PDF Cleaner opens in your browser. Close the window to stop.
- Everything still stays on your computer. The app listens on `127.0.0.1` only and makes no internet requests.
- Prefer Python? `start.bat` still works the same way.

### Find duplicates

- Click **Find duplicates** above the file list.
- Finds PDFs with **exactly the same contents**, even if they have different names or are in different folders.
- It's quick: it compares file sizes first, then fingerprints (SHA-256) only files that share a size.
- Choose which copy to keep in each group (the oldest is suggested), then click **Move copies to Recycle Bin**. You'll see the full list of files and must confirm before anything moves.
- At least one copy of every file is always kept. Each file is checked again just before it moves, and anything that changed is left alone.
- If some files can't be moved (for example, because they're open in another program), the others still go, and you get an exact list of which files were moved and which weren't.

### Show in folder

- Click **Show in folder** (or press `O`) to open File Explorer with the file selected.

## Upgrading from 1.0.0

Your saved decisions now live in `%LOCALAPPDATA%\PDF Cleaner\progress.json` instead of a `data` folder next to the program. To bring your 1.0.0 progress along:

- **Running from source:** nothing to do. On first start, 1.1.0 copies your old `data\progress.json` to the new place, and leaves the original.
- **Using `PDFCleaner.exe`:** put the `.exe` in your old PDF Cleaner folder (next to `start.bat`) for its first start, or copy `data\progress.json` to `%LOCALAPPDATA%\PDF Cleaner\` yourself.

## "Windows protected your PC"

`PDFCleaner.exe` isn't signed with a paid code-signing certificate, so Windows SmartScreen may warn you the first time. Click **More info** → **Run anyway**. To check you have the official file, compare its checksum:

```powershell
Get-FileHash .\PDFCleaner.exe
```

| File | SHA-256 |
|---|---|
| `PDFCleaner.exe` | `0fa48dd495289de4ca49470ee67e99b10bb5ad3e952ea953ae05bb6583608792` |

*(Maintainers: if the `.exe` is rebuilt before publishing, replace this with the checksum `build_exe.py` prints.)*

## Testing

- 50 automated tests, all passing on Windows 11 with Python 3.10.7, including:
  - duplicate grouping by content (not name), size pre-filtering, cancel, and skipping online-only files;
  - every batch-removal safeguard: confirmation, never removing all copies, refusing non-duplicates and outdated results, re-checking contents, a missing kept copy, and **exact reporting when a batch partly fails**;
  - Show in folder, including refusing unknown or recycled files;
  - the new data folder and one-time progress migration;
  - smoke tests of the built `PDFCleaner.exe` with Python hidden from it (serves the app, scans, finds duplicates, saves progress in the user folder, allows only one running copy, `--version`);
  - the opt-in real Recycle Bin tests for single and batch removal.
- Checked by hand: duplicate window and confirmation in light and dark mode and at phone width, Show in folder opening File Explorer on the right file, and the `.exe` folder picker.
